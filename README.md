# ☕ Starbucks Sales Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Starbucks Sales Dashboard** created using Microsoft Power BI. The dashboard helps analyze sales performance, understand customer purchasing patterns, and identify business trends through meaningful visualizations.

The goal of this project is to transform raw sales data into useful insights that support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track key performance indicators (KPIs).
- Understand sales trends over time.
- Identify popular products and categories.
- Explore sales patterns using interactive filters.
- Present business insights through clear visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **Data Visualization**
- **DAX** – Measures and calculations

## 📈 Dashboard Highlights

- Total Sales analysis
- KPI cards for key metrics
- Sales trend analysis
- Product performance analysis
- Category-wise sales insights
- Interactive slicers and filters
- Data-driven visual storytelling
